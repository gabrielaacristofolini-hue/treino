# Treino

Rotina de treino em dois treinos alternados (A e B) e acompanhamento diário a partir de 10/11/2026.
Site estático, sem build, feito para o GitHub Pages.

- `index.html`: a página
- `dados/treinos.js`: o plano (exercícios) e os registros de cada dia treinado
- `js/app.js`: cálculos e gráficos (calendário, mês em anel, semanas, histórico)
- `js/corpo.js`: mapa muscular em SVG
- `css/estilo.css`: visual

Para registrar um treino, basta acrescentar um item em `registros` no arquivo `dados/treinos.js`.
